# ЖД-Автоматизация — программа для скачивания

**Текущая версия: 2026.08.08.1051**

## Установка

1. Скачайте файл **ZHD-Avtomat-Setup.exe** (нажмите на имя файла в списке выше, затем кнопку скачивания).
2. Запустите его двойным кликом и нажмите «Установить».
3. Готово: на рабочем столе появится ярлык «ЖД-Автоматизация», программа откроется сама.

Права администратора не нужны, ничего распаковывать не нужно.

<details>
<summary>Если установщик не запускается (запрещён политикой предприятия)</summary>

Скачайте **ZHD-Avtomat-Windows.zip**, распакуйте его в любую папку
(правой кнопкой — «Извлечь всё…»), откройте папку ZHD-Avtomat и
запустите **ZHD-Avtomat.bat**. Не запускайте файл прямо из окна
архиватора — сначала распакуйте.
</details>

## Первый запуск

Программа покажет отпечаток вашего компьютера и попросит файл лицензии.
Отправьте отпечаток поставщику, получите файл `.lic` и загрузите его
прямо в открывшемся окне.

## Обновления

Программа сама проверяет новые версии и показывает уведомление.
Обновление ставится одной кнопкой, данные при этом сохраняются.
